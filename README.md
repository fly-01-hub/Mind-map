# 枝间 · 个人知识思维导图

枝间是一款 Local-first 的个人思维导图、大纲笔记与论文阅读工具，两种编辑视图共用同一棵节点树。用户的主要使用和后续验收场景是思维导图：参考幕布的编辑与多选操作，借鉴 Logseq 的 PDF 批注引用工作流，但不宣称完整复刻两款产品。所有资料写入当前浏览器或桌面应用自己的 IndexedDB，不需要固定公网网址、注册、登录或配置云数据库。

当前源码版本为 **1.7.0**，新增个人安卓平板 APK；本机已安装的 Windows 程序仍为 1.6.0。新对话或新开发者请先完整阅读 [redme.txt：功能、逻辑与 AI 接手说明](redme.txt)，其中包含用户最新需求、功能边界、源码/安装包区别和验证日期。

## 已实现的能力

- 导图和文档大纲均支持 `[[文档名称]]` 双向链接：实时高亮、双击打开或新建文档、反向引用定位来源节点；笔记预览也支持。重命名同步更新现有引用，旧名称兼容历史内容。操作与边界见 [文档双向链接](docs/DOCUMENT_LINKS.md)。
- 大纲与思维导图共用同一棵节点树；无视图偏好时默认大纲，切换后记住选择，用户主用导图
- 大纲支持 Enter 拆分/新建同级、Tab 缩进、Shift+Tab 提升、Shift+Enter 编辑描述、行首 Backspace 合并、方向键跨主题和拖动重排
- 双击导图节点按点击位置编辑，鼠标拖选部分文字后可用 Backspace/Delete 批量删除；编辑文字不会变为删除整节点
- 选区富文本随文档保存；大纲支持粗体、斜体、下划线、删除线、颜色、高亮、链接、代码和挖空，导图的局部链接建议切到大纲编辑
- Ctrl/Shift 点击圆点可多选主题，并批量复制、剪切、移动、完成、折叠或删除；可选层级编号
- 单侧右向脑图、双击局部富文本编辑、Shift 点击/方向键/空白拖框多选、中键或空格自由平移、整组拖动/换父级、批量主题栏、分层折叠、右键菜单、Focus Mode、撤销/重做
- Node Inspector：Markdown/LaTeX/代码、待办、标签、链接、颜色、图标、PDF/图片/普通附件
- IndexedDB 自动保存、刷新恢复和每份文档最近 50 个持久化历史版本；内存撤销栈另行维护、不跨重启，文件夹变化立即保存
- 网页安装版会在重新聚焦和定时检查时自动获取更新，避免长期停留在旧缓存版本
- 全文搜索、收藏、嵌套文件夹、拖拽归档、回收站
- 导图内直接创建概要和点选式跨主题连接线；图片可通过 Alt+Enter、拖放或系统剪贴板直接加入主题；另含四套配色、紧凑布局、严格只读浏览与演示模式
- Markdown、OPML、FreeMind、现代 XMind 导入；Markdown、OPML、FreeMind、XMind、HTML、完整 2× PNG 与打印/PDF 导出
- PDF 可从资源管理器直接拖到导图节点，自动生成论文子节点；内置 PDF.js 分页阅读、全文搜索、缩放、阅读进度恢复与离线保存
- PDF 淡色文字高亮、1px 下划线、五色批注、标签、图表区域截图与重新框选；原文批注独立保存
- 可见“矩形高亮”入口：鼠标自由拖框，五色半透明整块填充，文字/图表/扫描页均可用；有文字层时提取区域文字，否则保留截图，Esc 取消
- 批注关联已有节点或生成子节点，多对多实时引用；可拖动批注卡片到导图节点，或复制引用后粘贴关联
- 拖入 PDF 创建文献节点、单击文献节点打开左 PDF / 右导图；分栏中新保存的标注自动生成打开的文献节点的子节点，也支持连续划选即标注；独立阅读页手动生成/关联
- 节点来源徽标与预览卡片、批注反向节点列表、精确定位与关联撤销；下划线不会绘制整框定位描边
- 跨论文批注管理：按文字、颜色、标签、论文或未关联状态筛选，批量引用到多个节点
- 论文与节点多对多关联、SHA-256 去重，以及保留论文标题、页码、引用和笔记的 Markdown 导出
- `.researchmind` 完整备份与原子恢复，覆盖导图/大纲、嵌套文件夹、回收站、历史、附件、PDF、批注、引用关系及阅读页码/缩放；恢复是整体替换，不是合并，界面偏好和内存撤销栈不在备份内
- 预留 AIProvider/PaperAIProvider 接口；当前 Mock 返回“未启用”，不联网，不具备真实 AI 总结、OCR 或自动语义分区
- PWA 离线应用壳、桌面安装入口，以及独立的 Windows `.exe` 安装包
- 知识库 `Ctrl+K` 搜索、`Ctrl+N` 新建，编辑器显式新增主题入口和可记忆宽度的详情栏

## 1. 安装 Node.js

安装 [Node.js](https://nodejs.org/) 24 或更新版本。安装完成后打开 PowerShell，输入：

```powershell
node --version
npm --version
```

## 2. 安装并运行

```powershell
cd D:\app\siweidaotu
npm ci
npm run dev -- --host 127.0.0.1
```

终端会显示本地网址，通常是 `http://127.0.0.1:5173`（端口被占用时以终端为准）。用 Chrome 或 Edge 打开即可进入知识库。单独运行 `npm run dev` 不显式指定该主机地址；不同主机名/端口的数据空间不同，不要混用地址后误以为资料丢失。

## 3. 安装到 Windows

### 使用 `.exe` 安装包

运行 `release/ResearchMind-Setup-1.6.0-x64.exe`，按向导选择安装目录。升级前先创建完整备份并关闭旧程序。桌面版使用固定的 `app://researchmind` 本地来源，数据保存在 Windows 当前用户的 ResearchMind 应用数据目录中。

当前个人版本未使用可信商业代码签名。SmartScreen 或应用控制可能提醒或拦截，不能保证任意 Windows 电脑都免警告。请保留系统安全功能，不用关闭保护、改名或改哈希规避；遇到拦截可使用本地网页/PWA。下载安装包前核对来源。

2026-10-04 经用户授权，已在原目录升级安装 1.6.0（ProductVersion 1.6.0.0），安装退出码 0，旧 1.5.2 程序已替换。安装前完整复制应用配置目录并逐文件校验；升级后、首次启动前 83 个资料文件完全一致。已用实际安装 EXE 检查知识库和已有导图，并在独立配置目录验证双向链接及关闭重开。备份位置和验收记录见 [文档双向链接](docs/DOCUMENT_LINKS.md)。自动化启动时仅清理子进程的 `ELECTRON_RUN_AS_NODE`，不改变系统环境或安全设置。

网页和桌面版的数据空间彼此独立。首次切换时，请先在旧版本创建 `.researchmind` 备份，再到新版本执行“从备份恢复”。

重新生成安装包：

```powershell
npm run desktop:build
```

仓库配置了 `v*` 标签触发的 GitHub Actions 构建/发布流程，以实际远端执行结果为准；本地改源码不会自动更新已安装 EXE 或以前的公网网站。`release/` 被 Git 忽略，普通 push 不上传本地安装包或个人数据副本。

## 4. 创建本地备份

### 安卓平板安装与电脑资料迁移

将 `release/ResearchMind-1.7.0-android.apk` 复制到平板，使用系统安装器安装。最低安装系统为 Android 9（API 28），同时需要设备可用的新版 Android System WebView；APK 内置页面，不依赖开发服务器或应用账号。旧系统自带 WebView 不保证兼容当前编辑器/PDF.js。不要关闭设备安全保护来绕过安装拦截。

电脑上创建 `.researchmind` 完整备份 → 将该文件复制到平板 → 平板打开“备份与恢复 / 从备份恢复”。文件夹层级、回收站、导图及关联内容会一并恢复。恢复会整体替换平板当前资料，不能自动合并两台设备的编辑，也不提供云同步。Windows 应用配置目录副本不能直接导入安卓。

安卓支持系统文件选择/保存、分块导出、取消保存、系统打印入口和触屏双击链接；单次导出上限为 512 MB。当前 APK 使用本机 Android 调试密钥签署的非调试 release 构建，适合个人安装，不是商店发布包；密钥不要上传，后续覆盖升级必须使用同一密钥。构建方式、安全边界和验证记录见 [安卓交付说明](docs/ANDROID.md)。

### 完整备份与恢复

1. 在知识库右上角点击“备份与恢复”。
2. 点击“创建完整备份”。
3. 把 `.researchmind` 文件保存到安全的本地文件夹或移动硬盘；如果你自己使用同步盘，也可以选择它的本地同步目录。
4. 建议在重要编辑后或每周创建一次新备份，并保留最近几份。

恢复时点击“从备份恢复”并选择 `.researchmind` 文件。恢复在校验成功后整体替换当前应用数据，不是合并；数据库写入失败时事务回滚。恢复前建议先备份当前资料。

保存备份的文件夹只需保管好其中的 `.researchmind` 文件；换设备后选择该文件即可恢复。不是任意文件夹都能作为备份自动恢复，也不需要依赖原始附件/PDF 的外部路径。

> 浏览器站点数据或桌面配置中的 IndexedDB 是日常主存储；备份文件没有加密。清理配置、重装系统或更换设备前，务必先备份，并不要把个人备份提交到 Git。

## 6. 本地运行原则

原生桌面版和本地网页/PWA 都不要求应用账号，资料留在对应本地数据库。开发时显式运行 `npm run dev -- --host 127.0.0.1`。PWA 缓存应用壳需要先成功加载构建页面，首次打开和更新仍需可访问来源；桌面 `app:` 不注册网页 Service Worker。用户主动打开外部链接或网页检查更新可能联网，不代表上传资料。

2026-10-04 双向链接更新通过 47 项单元测试、60 项浏览器测试、类型检查与 lint，另完成可见 Chrome 链接专项与隔离 Electron 桌面验证。`desktop:test` 默认使用独立临时配置与包内真实桌面壳；设置 `RESEARCHMIND_INSTALLED_EXE` 可对指定的已安装 EXE 做同样的隔离验收。用户随后授权安装，本机现已升级至 1.6.0，实际安装程序的验收通过。详细记录见 [文档双向链接](docs/DOCUMENT_LINKS.md)。测试覆盖不等于所有历史数据、所有设备都无缺陷。

## 当前边界

无账号/云同步/网盘 API、OCR、真实 AI、PDF 批注写回、连续多页阅读、区域边缘调整把手或完整手机编辑。格式交换不保证全部字段无损：OPML/FreeMind 导入主要读结构，XMind 只支持现代格式首个 sheet；Markdown/PNG/打印 PDF 不能替代完整备份。更多差异见 [已知限制](docs/KNOWN_ISSUES.md) 和 [接手说明](redme.txt)。

## 目录

- `src/adapters/mindmap/`：Mind Elixir 的唯一适配边界
- `src/features/`：知识库、编辑器、备份恢复、Node Inspector 和论文阅读器
- `src/stores/`：文档、选中、UI、保存与本地用户状态
- `src/db/`、`src/repositories/`：Dexie 数据库、迁移和数据访问
- `src/services/`：本地持久化、完整备份、PDF 解析、来源导出和 AI 扩展接口
- `e2e/`：真实浏览器关键流程
- `docs/`：产品、架构、数据模型、快捷键和限制
