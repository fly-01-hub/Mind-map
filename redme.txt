一、给新对话 AI 的快速说明（请先读）

这是一个个人使用、免费、本地优先的 Windows/安卓平板思维导图与论文阅读应用。
用户最常使用“思维导图模式”，长期目标是尽可能完整复现幕布的功能和操作体验，包括排版、编辑、多选、移动等。
这是用户的目标，不是当前已达成的结论；现有实现和与幕布/Logseq 的差异必须分别说明，不能把核心操作已实现当作完整对等。
论文功能借鉴 Logseq 的“独立批注对象、节点引用、反向引用、区域摘录”，但适配思维导图。
当前核心场景：建立导图 → 直接拖入 PDF → 文献节点 → 单击打开左 PDF / 右导图 → 批注自动成为文献子节点 → 双向定位原文 → 完整本地备份。
不要重新引入 Supabase、账号登录、固定公网网址申请、付费 API 或强制联网。
用户以前尝试过 Supabase/Vercel/GitHub 授权，但后来明确改为本地独立使用；旧部署不再是默认工作路线。
百度网盘只可以由用户自行保存备份文件，没有百度网盘登录、API 对接或自动同步功能。
当前是独立实现，不是幕布或 Logseq 的源代码/品牌复制，也不能宣称已经完美实现它们的全部功能。
当前框架可在必要时重构，但优先修复真实交互问题、保护资料；不要为了换框架破坏已有功能。

最重要的兼容约束：
1. 双击节点按点击位置编辑；可以鼠标拖选部分文字并用 Backspace/Delete 批量删除，不退出节点。
2. 文字选区与节点多选是两套不同状态；编辑文字时不得执行整节点删除或拖动。
3. 中键按住拖动、空格+左键拖动平移画布；松开空格/失焦必须释放平移状态。
4. 空白处左键拖框只选择节点，不立即删除。早期“从上往下/从下往上框选即删除”要求已被幕布式安全多选替代，不要恢复。
5. 多选后能批量移动到另一父节点、拖动整组、同级排序、复制/剪切/删除和撤销。
6. 保留用户偏好的单侧向右分支；用户曾要求回退新改的分支造型，不要擅自重做为强制对称布局。
7. 图片要能粘贴/拖入主题直接显示；PDF 要直接拖入生成文献节点，不要求先手工上传。
8. 论文分栏必须是左侧 PDF、右侧导图（不是相反）。分栏标注自动挂到打开的文献节点，不随临时导图选中节点漂移。
9. 下划线是细线，高亮是淡色透明覆盖；不要用整段绿色矩形框遮挡正文。矩形高亮必须整块填充，而非仅描边。
10. 维护后按数据一致性、真实交互/视觉、边界/全量回归三轮自审；发现问题先修复，不能只编译成功就宣称桌面可用。

三、知识库与文档管理

1. /library 是默认入口；无需注册或登录。/login 仅兼容旧链接并重定向知识库。
2. 新建、打开、重命名导图；中心主题标题与文档标题同步。
3. 列表/卡片视图，记住当前配置的选择；展示文档、节点、文件夹数量和本地保存信息。
4. 收藏、按标签筛选、搜索文档及节点内容、按文件夹查看。
5. 支持嵌套文件夹：顶层新建输入名称后按 Enter 或确认按钮；子文件夹从文件夹菜单建立。
   新建/重命名/删除文件夹会立即触发持久化，不依赖普通文档的 350ms 等待。
6. 导图可拖到文件夹归档，或从菜单移动；未分类文档不要求归属文件夹。
7. 删除文件夹及其后代是软删除，其中的文档进入回收站，不等于永久清除论文资料。
8. 文档回收站支持恢复；永久删除需确认，清理该文档、历史、附件和相关节点关系，不删除共享论文及其批注。
9. Ctrl+N 新建、Ctrl+K 搜索；“论文与批注”入口进入 /annotations；“备份与恢复”创建/恢复完整备份。
10. 第一次初始化空数据库时会写入示例导图与“科研资料/创作计划”文件夹；不要误认为这些示例就是用户全部需求或真实资料。

四、双视图、编辑与节点内容

1. 大纲和导图共用一个 NodeData 树，没有两份独立内容；切换后内容、格式和结构保持一致。
   当前代码没有视图偏好时默认大纲，localStorage 的 zhijian-editor-view 会记住导图选择。
   “默认大纲”是现有行为，不代表用户更喜欢大纲；后续验收以导图场景为优先。
2. 导图单侧向右排布，有纸张绿、海洋蓝、暖棕色、黑白灰四套配色和紧凑布局。
3. 单击选中节点；双击进入标题编辑并尽量把光标放在点击位置。新建节点会进入编辑。
   鼠标拖选文字、Backspace/Delete、局部样式、输入法组合态必须留在编辑框内。
   点击编辑框外提交；Escape 取消当前编辑/关闭当前操作，具体按所在上下文处理。
4. 节点内容包含：纯文本标题、局部 HTML 富文本、Markdown 描述/笔记、代码、LaTeX 公式、表格、标签、超链接、图标、颜色、图片、普通附件及任务状态。
5. 待办状态 none/todo/doing/done；支持添加待办、完成/取消完成，允许批量处理。
6. 局部格式包含粗体、斜体、下划线、删除线、文字颜色、代码、挖空；大纲另有选区高亮和超链接工具。
   导图局部超链接仍建议切到大纲编辑，整主题链接可用详情栏；不要把两种视图的工具覆盖度说成完全相同。
7. 节点详情栏可编辑 Markdown，预览公式、代码与表格；表格用制表符/分行输入。
   详情栏按需加载，可收起，宽度记忆（当前约 300–520px）；描述可通过 Shift+Enter 聚焦。
8. 大纲可显示层级编号，描述内联显示；拖动主题前/后/内侧对应重排或换父级。
9. Focus Mode 只查看某个子树，面包屑返回上层；不是复制或拆出另一份文档。
10. 只读浏览和演示模式封住结构编辑、详情、键盘写入和文件拖入；演示仍可平移、缩放。

五、导图选择、移动、平移与删除

1. Shift+点击节点增减多选；Shift+上下方向键按可见主题顺序扩展选择。
   空白处按住左键拖动是框选，框选结束保留结果；普通空白点击取消选择。
   普通单击一个主题会从整组选中缩小到该主题；已选节点拖动时保持整组。
2. Ctrl+A 选择当前可见主题；折叠分支内隐藏节点不算独立可见选择。
3. 选中多个主题后：底部主题操作栏/移动面板移动到另一个父主题、复制、剪切、粘贴、待办、完成、折叠、删除。
   拖动已选主题可整组移动；Ctrl+Shift+上下在同级中移动。
4. 移动过滤祖先/后代重复选择，按文档顺序处理；不允许把节点移到自身或后代形成环。
5. 中键拖动画布，或按住空格再左键拖动；应用自己的平移增量绕过引擎边界夹紧。
   鼠标抬起、松开空格、窗口失焦和组件退出清理状态，避免卡在抓手模式。
6. 缩放百分比、放大/缩小、适应画布、居中；导图平移/缩放不是文档内容，不写入数据库。
7. 明确 Delete/Backspace 或删除按钮才删除节点及其子树；编辑文字时只删文字，根主题不能按普通子树删除。
   “仅删除当前主题、保留下级”是另一个明确命令，不要与删除分支混淆。
8. 撤销 Ctrl+Z，重做 Ctrl+Y/Ctrl+Shift+Z；结构和关联线/概要进入每文档的内存撤销栈，最多保留 50 个过去快照。
   内存撤销历史不跨应用重启；持久化“历史版本”是独立功能，不要混为一谈。
9. 概要只能覆盖两个或更多相邻同级主题；非连续或不同父级不能生成有效概要。
10. 关联线从当前主题选择目标创建；文档保存箭头/概要，删除节点会清理失效的线并校正概要。
11. 搜索结果会展开目标祖先路径、选中/定位/居中，不会误进入孤立的 Focus 分支。

六、常用快捷键（以编辑/非编辑上下文区分）

导图：
Enter：提交编辑并新建同级；Tab：新建下级；Shift+Tab：提升一级。
Shift+Enter：编辑描述；双击：局部文字编辑；Escape：取消/退出当前操作。
Ctrl+C/X/V：非文本编辑时复制/剪切/粘贴子树或整组；文本编辑时使用普通文本剪贴板。
Ctrl+D：分支副本；Ctrl+Shift+Backspace：删除分支；Delete/Backspace：非编辑时删除选中主题。
Ctrl+Shift+L/K：待办/完成；Ctrl+Shift+上下：同级排序。
Alt/Ctrl+.：当前折叠；Ctrl+Shift+.：同级折叠；Ctrl+Alt+1/2/3：显示分支到指定层级。
Ctrl+B/I/U、Ctrl+Enter、Alt+D/R/Y/G/B/P：主题样式；编辑中作用于文字选区。
Alt+L：选区行内代码；Ctrl+Shift+X：挖空；Alt+Enter：插入本地图片。
Ctrl+F：导图搜索；Ctrl+/：帮助；Ctrl+]：进入主题；Ctrl+[：返回上级。
Ctrl+Alt+Shift+M：双视图切换；Ctrl+Alt+Shift+P：演示切换。

大纲：
Enter 在光标处拆分并新建同级；Tab 缩进到上一同级主题下；Shift+Tab 提升。
行首 Backspace 合并到上一可见主题；Shift+Enter 进入/退出描述。
Ctrl+点击圆点增减多选，Shift+点击圆点范围选择；方向键在文字边界跨主题。
选区工具栏支持局部高亮/链接；Ctrl+K 编辑选区链接（知识库的 Ctrl+K 是搜索）。

PDF：
Ctrl+F 全文搜索；Ctrl++/Ctrl+= 放大；Ctrl+- 缩小；上下/左右翻页。
Escape 关闭搜索/选区并取消区域框选；输入框内方向键不拿来强制翻页。
内嵌 PDF 快捷键只在阅读区获得焦点时处理，不抢走右侧导图的编辑键。
中文输入法组合期间 Enter 确认候选，不执行拆分/新建等结构命令。
完整快捷键清单及上下文见 docs/SHORTCUTS.md、MapEditorPage.tsx、OutlineEditor.tsx。

七、图片与附件

1. Alt+Enter 或主题栏“图片”选择本地图片；也可把图片拖到主题或粘贴系统剪贴板图片。
2. 图片作为 NodeData.image 的本地 data URL 直接显示，当前每个主题只有一张主图片，后插入的主图会替换原图。
   同一次拖入多文件时第一张图片为主图，其余图片作为普通附件；不是无限图片画廊。
3. 普通附件元信息留在节点中，二进制 Blob 在 attachmentBlobs；图片/PDF/普通文件有相应预览/下载入口。
4. 导图拖入 PDF 和详情栏关联 PDF 有区别：前者生成文献子节点，后者也可直接关联当前已有主题。
   PDF 不再统一当普通附件；旧附件可以兼容展示。
5. 上传/拖入只是从本地文件复制到本地资料库，不发送给云端；不依赖外部原文件路径一直存在。

八、论文阅读与批注的完整逻辑（当前重点）

1. 从资源管理器直接把一个/多个 PDF 拖到主题或空白处。
   主题上以该主题为父级；空白处优先选中主题，无选择则根主题。每篇建立带 📄 图标的文献子节点。
   校验 PDF 文件头并解析后再建立文献节点；损坏 PDF 不应留下空的文献主题。
   文件内容 SHA-256 去重，相同字节复用 Paper/PDF Blob，但可关联多个导图和节点。
2. 单击文献节点打开“左 PDF / 右导图”；双击取消延迟打开并编辑标题（单击打开有约 400ms 延时避让双击）。
   顶栏“论文分栏”可以选择已有论文；/annotations 可直接导入资料；/paper/:paperId 保留独立阅读。
3. PDF.js 一次渲染一页，支持页码输入、翻页、50%–250% 缩放、适应宽度和阅读页码/缩放恢复。
   文本全文搜索按页提取文本并在本次会话缓存；无需预先渲染所有页。
   PaperReadingState 类型有 scrollOffset 字段，但当前阅读器主要恢复页码/缩放，不保证恢复精确页内滚动。
4. 有文字层时鼠标拖选文字，浮动栏选择高亮、下划线或笔记批注；五色为黄/红/绿/蓝/紫。
   阅读栏可选“划选即高亮/划选即下划线”，连续创建证据；手动模式仍需明确点击保存。
5. 当前 1.5.2：下划线约 1px，只在文字底部；高亮为淡色透明覆盖，取消碎块边框和阴影。
   选区按实际 TextLayer 文本节点范围取矩形，同基线相邻片段合并，跨列/上下行/上标不错误合并。
   旧文字批注可用摘录与最近原坐标重新锚定显示；找不到可靠匹配时回退原坐标，且不改写旧记录。
   文字来源定位滚动到标记，不额外画大绿色边框；历史错误坐标不保证所有 PDF 都能自动修复。
6. “矩形高亮”：点击可见按钮，左键自由拖矩形，正反方向均可；裁剪页边界，拒绝太小区域。
   松手显示预览/工具条，选颜色再点“保存区域高亮”，整个矩形透明填充；Esc 可取消、不保存。
   有文字层时附区域内字符摘录；无文字层时仍能高亮并保留截图，但不会 OCR。
7. “区域批注”：拖框摘取图表、图片、公式，保存本地 PNG 与归一化矩形；默认描边样式。
   区域截图取 PDF Canvas 本身，不把已有标注绘进截图；最大边约 1200px。
   两种区域都属于 annotationType=area，areaStyle=highlight/outline；历史缺失 areaStyle 默认 outline。
8. 内嵌分栏保存新批注时自动在“打开的文献节点”下面创建子节点；中途选中别的主题不改变父级。
   区域子节点附截图；文字子节点用摘录做标题，来源对象保留完整原文、页码和位置。
   文献父节点被删除则阻止过期写入；不把证据悄悄挂到另一个选中节点。
   自动生成只针对这次新保存的批注，不会自动把所有旧批注补成子节点；独立阅读页手动选择生成/关联目标。
9. 批注是独立源对象：PaperAnnotation 保存摘录、共享笔记、页码、颜色、标签、区域图及稳定 ID。
   节点个人笔记独立保存；关联已有节点不覆盖其标题或笔记。
   同一批注可引用到多个节点/导图，节点也可引用多个批注；创建关系时也建立论文关联。
10. 批注卡片：编辑笔记、标签、五色；通过拖动柄拖到明确主题引用；复制引用后在非文字编辑状态粘贴关联。
    本地引用形式 researchmind://annotation/<id>，仅由应用解析，不是联网 URL，也未注册为系统级外部协议。
    拖到画布空白不会猜测关联根主题；重复关联复用关系身份，不制造重复引用。
11. 节点 📄 来源徽标/来源面板展示论文标题、页码、原文、笔记和区域截图；点击定位到相应页和标注。
    反向引用显示关联节点，点击展开/定位导图；反复点同一来源仍定位，不重载整篇 PDF。
12. 重新框选区域更新原批注位置和预览，不新建节点，不丢 ID、标签、笔记、颜色或引用。
    仅更新仍使用旧自动截图的节点图片，不覆盖用户自行换的图片。
    当前重新框选不自动改写旧摘录/节点标题；没有边缘拖动缩放把手。
13. /annotations 跨论文批注管理：关键词、论文、颜色、标签、仅未关联筛选，批量关联多个目标节点。
14. 解除关联只软删除该关系；删除批注需要保护提示，只软删除源批注，不连带删除节点或个人笔记。
    反馈中的撤销恢复批注/关联。撤销新建证据节点不等于删除独立批注；恢复节点后可恢复显示来源。
15. 创批注+生成节点+两个关系在同一数据库事务中完成，并检查目标文档未被其他编辑更新，避免部分写入/过期覆盖。

九、本地保存、历史与备份

1. 日常存储：Dexie/IndexedDB，数据库名 zhijian-knowledge-db，schema version=3。
   文档修改通常 350ms 防抖保存；文件夹变化立即保存；PDF、批注、引用的写入走独立 repository/service。
   保存状态：正在保存 / 已保存到本地 / 保存失败；异常断电或强制结束进程仍可能丢失未落盘操作。
2. 持久化版本：保存时满足约 120 秒间隔才建立 interval 快照，另有重要操作/恢复前快照；每文档最多 50 条。
   不是每个按键都创建一个历史版本，也不是没有修改时自动定时备份。
3. 当前 11 张表：documents、folders、versions、attachmentBlobs、papers、paperFiles、paperReadingStates、paperAnnotations、nodePaperRelations、annotationNodeRelations、meta。
4. Windows 桌面来源 app://researchmind，应用数据根目录本机为：
   C:\Users\19555\AppData\Roaming\ResearchMind
   默认 IndexedDB 文件位于该配置目录内的 IndexedDB 子目录；不要在应用运行时手工修改数据库文件。
5. 网页 localhost/127.0.0.1、不同端口、不同公网域名、不同浏览器配置及桌面 app://researchmind 是不同存储空间。
   没有自动互通；“升级源码/换网址”不会自动迁移旧浏览器资料。迁移用完整备份，不能当作资料突然丢失而清库重建。
6. 知识库“备份与恢复”创建 .researchmind：先 flush 文档，再读事务快照全部表，把 PDF/附件 Blob 编为 Base64。
   format=researchmind-local-backup，version=1；含删除记录、历史、批注/关系、区域 PNG 和阅读页码/缩放。
7. 恢复是校验/解码后，在一个读写事务中整体替换当前数据，不是合并；写入失败回滚。
   恢复前必须明确确认并建议另备份当前资料；不要对用户真实库自动做覆盖式测试。
8. localStorage 的界面偏好（视图、编号、详情宽度、列表形式）、内存撤销栈、临时选区和搜索缓存不包含在完整数据库备份内。
   备份不是加密文件；Base64 也不是加密。不要提交用户备份/PDF/截图/浏览器配置到 Git。
9. 清理站点数据、删除桌面配置、卸载/重装环境或系统前先备份。版本号相同的不同运行环境也不会共享资料。
10. 可将备份放本地、移动硬盘或用户自选的同步盘目录；应用本身没有后台网盘服务。

十、导入导出边界

1. 导入：Markdown（本应用可逆元数据注释）、OPML、FreeMind .mm、现代 XMind .xmind（content.json）。
2. 导出：Markdown、OPML、FreeMind、XMind、HTML、官方导出插件的完整 2× PNG、打印/保存 PDF。
   PNG 在导图模式执行；打印 PDF 依赖打印界面，不是把论文批注写回原 PDF。
3. Markdown 的 zhijian-node HTML 注释保留富文本、笔记、标签、任务、链接、代码、公式、样式和表格；来源输出论文标题/页码/摘录/共享批注笔记。
   Markdown 不完整保存图片/二进制附件、全部图关系、PDF 文件或可继续定位的引用关系；不能替代 .researchmind。
4. OPML/FreeMind/XMind 是结构交换，不保证所有格式/备注往返：当前 OPML/FreeMind 导入主要读标题及层级，不回读导出的全部备注。
   XMind 只读第一个 sheet，含 attached/detached 主题及纯文本 notes；不支持旧 XML、多 sheet 全量或完整专有样式。
5. HTML 是静态大纲展示，不是完整可恢复应用数据库；PNG 受 Canvas 尺寸/内存限制。
6. 不要把“支持导入导出”说成所有格式无损互转；完整迁移资料只能用 .researchmind。

十二、运行、构建、桌面安全与升级

开发环境建议 Node.js 24（CI 使用 24）；依赖安装要联网，日常本地功能不要求联网。
PowerShell 在项目目录：
  npm ci                                 按锁文件安装；修改依赖时才用 npm install
  npm run dev -- --host 127.0.0.1         启动本机开发网页，通常 5173，端口被占用时看终端

  npm test                               单元测试

  npm run test:e2e -- --list               仅列测试，不是执行通过
  npm run lint                           oxlint
  npm run build                          构建网页到 dist
  npm run preview -- --host 127.0.0.1     预览已构建网页（通常 4173，存储来源又不同）
  npm run desktop:start                  先构建，再用 Electron 打开本地打包页面
  npm run desktop:unpacked               Windows 免安装构建到 release/win-unpacked
