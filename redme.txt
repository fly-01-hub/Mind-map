4. 本地资料、保存与备份
============================================================

数据库 zhijian-knowledge-db，schema version 3，共 11 张表：
documents、folders、versions、attachmentBlobs、papers、paperFiles、paperReadingStates、paperAnnotations、nodePaperRelations、annotationNodeRelations、meta。
初始化只补 initialized 元信息；不生成样例，不清空已有记录。
文档约 350ms 防抖保存，文件夹立即保存；队列串行执行，防旧保存覆盖新状态。
持久化快照约 120 秒触发，每文档最近 50 条；内存 undo/redo 不跨重启。
PDF Blob 在 paperFiles，用 SHA-256 去重；附件在 attachmentBlobs，不依赖原外部文件路径。
批注/节点/论文关系事务维护；解除引用不等于删除论文或批注。

完整备份：单个 .researchmind，标识 researchmind-local-backup，格式 version 1。
包含全部 11 张表、PDF/附件二进制（Base64）、历史、回收站、批注和关系。
恢复先校验，再单个事务整体替换全部表，失败回滚；不是合并或自动同步。
不包含程序、系统配置、localStorage 界面偏好、内存撤销栈。
备份未加密，Base64 不是加密；大资料库有体积和内存开销，不得公开上传。
Markdown/OPML/FreeMind/XMind 等不是全量备份，不能替代 .researchmind。

数据空间：
  本人原网页/PWA：http://127.0.0.1:4173。
  Windows 桌面：app://researchmind；用户目录以 app.getPath('userData') 为准，不凭名称猜。
  LAN HTTPS：https://192.168.1.19:8443（本机当前配置）。
  安卓：WebView 固定本地 HTTPS 来源，独立于以上空间。
localhost/127.0.0.1、HTTP/HTTPS、端口/域名或浏览器配置变化，都可能打开另一份空白库。
空白先核对来源/配置，不能立即判定资料被删，也不能擅自导入覆盖。
跨设备用用户明确选择的完整备份；Windows 配置目录副本不能直接导入安卓。

用户历史已确认备份完成，但最新有效完整备份路径未核实。

7. LAN HTTPS、证书与授权边界
============================================================

详见 docs/LAN.md。正式服务单私有 IPv4 网卡、allowedClientSubnets/Host 限制，不绑定 0.0.0.0。
HTTPS 最低 TLS 1.2，检查日期、非 CA 服务器证书、SAN 和私钥匹配。
只接受 GET/HEAD；只服务编译资源，拒绝源码、密钥、备份、PDF、source map 和路径穿越。
启动时读取编译文件到内存，更新 dist 后须正常重启服务。
PDF worker 必须存在并预缓存；有正确 .mjs MIME、SPA 深链接、SW no-cache 和哈希资源缓存。
127.0.0.1:5198 HTTP 是自动测试回环服务，不是 LAN HTTP 模式；正式 CLI 无 HTTPS 绕过选项。

本机配置（2026-10-12，不能照搬到其他机器）：
  listenAddress 192.168.1.19；port 8443。
  publicOrigin https://192.168.1.19:8443；allowedClientSubnets 192.168.1.0/24。
  certificateFile ../.lan-private/server-cert.pem。
  privateKeyFile ../.lan-private/server-key.pem。
其他网卡不可顺带暴露；由管理员安排固定 DHCP 地址/域名。改来源会变资料空间，证书也需核对。

用户明确授权：只生成受保护证书文件，不安装根证书、不改防火墙。
已用 Git 自带 OpenSSL（C:\Program Files\Git\usr\bin\openssl.exe）生成 RSA 4096 CA，签发原 RSA 3072 CSR；服务器密钥未替换。
CA 名称 ResearchMind LAN CA 728afe5a，有效至 2031-10-10。
服务器 SAN IP:192.168.1.19，有效至 2027-10-11；精确时间以证书为准。
CA SHA-256 指纹：
5C:0C:B1:22:39:38:BD:08:6A:64:94:33:06:22:06:CD:89:78:BF:DA:85:33:D5:40:72:96:AE:4F:79:EE:6C:DC
OpenSSL 严格证书链/sslserver/IP 核验、密钥匹配、公开导出一致性和 lan:check 通过。

绝不能分发：ca-key.pem、server-key.pem 或整个 .lan-private。
私钥未加口令；目录 ACL 仅部署用户、SYSTEM、Administrators。CA 私钥建议离线保管，运行服务不需要它。
可单独分发：.lan-private/client-trust/ResearchMind-LAN-CA.cer 与说明.txt；只有公开证书/说明。
公开 .cer 为 DER，其 SHA-256 文件哈希等于上述指纹去掉冒号；客户端须核对来源/指纹。
不要随意重建/覆盖 CA，避免破坏信任。lan:cert-request 只生成服务器 key/CSR，已存在时拒绝覆盖，不是 CA 自动续期。
