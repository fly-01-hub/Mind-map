# 节点输入与“＋”定位修复（1.7.1）

本文保留该功能引入版本的设计及历史测试记录；当前发行说明以 README.md 为准。新安装为空白，测试不使用用户日常知识库。

## 原因与修复

1.7.7 修复：隐藏 Mind Elixir 自带的展开/折叠按钮，只保留应用的浮动按钮。选中有子节点且已展开的节点时，显示一个折叠减号和一个添加子主题加号；折叠后原减号变为展开按钮。

当前交互：选中节点后显示添加子主题“＋”及展开/折叠按钮；鼠标悬停不显示未选中节点的按钮，也不移动已选中节点的浮动按钮。点击空白画布取消选择后隐藏按钮。编辑时按钮继续跟随输入框尺寸。

Mind Elixir 编辑时隐藏原主题，用独立的自动增长 `#input-box` 输入。原来的浮动按钮仍读取隐藏主题的旧尺寸，且仅在鼠标移动/窗口变化时更新。文字增加后按钮停留在旧位置；新建节点也可能尚未更新按钮锚点。

适配器标记当前编辑的节点 ID，定位时读取它的编辑框实际屏幕边界。尺寸/DOM/画布变换和滚动变化触发按帧合并的测量；没有空闲轮询，不重写编辑 DOM、不改变光标/选区或逐按键提交资料。结束编辑后回到主题边界；切换视图/节点时移除观察器。

同时修正浮动按钮和缩放控件的事件被当成空白画布点击的问题，取消过期的选中帧，并同步刷新后的引擎选区缓存。外观重排保留选中状态，避免影响反向链接的来源定位。
