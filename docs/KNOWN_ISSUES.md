# 已知限制

- 1.7.0 新增个人安卓平板 APK（安装最低 Android 9，还需新版 System WebView）。触屏双向链接、生产页面/PDF 和备份 UI 已有隔离测试；没有连接真实平板，因此系统文件选择器、软键盘和设备升级仍需真机确认。不是完整手机适配，也不保证老旧 WebView 兼容。
- 安卓单次导出上限 512 MB，超过时明确报错；使用系统文件保存器，不申请联网或所有文件访问权限。个人 APK 使用本机调试签名密钥，未来覆盖升级必须保留同一密钥，不能作为商店正式签名包。

- 1.6.0 的文档双向链接覆盖 `[[文档名称]]`、打开/新建、笔记预览和反向引用。当前不包含 Logseq 的块引用、页面嵌入、别名手工管理、自动补全或全局知识图谱；代码示例、空名称和跨行名称不生成链接。
- 旧同名文档仍可编辑和打开，但链接会要求选择目标；重命名前的名称保留用于历史解析，不能被另一活动文档重新占用。回收站同名文档恢复时可能追加数字后缀。

当前测试覆盖了核心编辑、保存、批注与构建场景，但不能视为所有设备和历史数据零缺陷。以下是明确的产品边界；最新交接和验证日期见 [redme.txt](../redme.txt)：

- 资料只自动保存在当前浏览器配置或桌面应用配置中，不会自动跨设备同步；不同主机名/端口/域名/浏览器和桌面的数据空间独立。清理配置或重装系统前必须先创建完整备份。
- 应用不连接任何网盘账号。完整备份由用户保存到本地文件夹或移动硬盘；如果用户自行使用同步盘，也可以选择其本地同步目录。
- 无视图偏好时默认大纲，切换后记住选择；用户主用导图，后续交互验收以导图为重点。引擎隔离在适配器内，必要时才替换，不应破坏已有本地数据。
- 导图已实现一批幕布式核心操作，但不能宣称覆盖用户所需的一切或完整复刻：固定为单侧右向结构，提供紧凑布局和四套配色，没有全部结构模板、在线协作、账号同步和会员功能。
- 导图局部富文本已支持粗体、斜体、下划线、删除线、颜色、代码和挖空；局部超链接仍建议在大纲视图中编辑，整主题链接可在节点详情中设置。
- XMind 导入支持包含 `content.json` 的现代 `.xmind` 文件；非常旧的 XMind XML 工作簿需要先用 XMind 另存为新版格式。
- `.researchmind` 文件中的附件和 PDF 使用 Base64 表示，文件会比原始二进制总量大约增加三分之一；超大资料库导出时会占用较多浏览器内存。
- 完整备份未加密，不包含 localStorage 界面偏好或内存撤销栈；恢复整体替换当前数据库，不是合并。Markdown/OPML/FreeMind/XMind 等交换格式不保证所有字段无损，不能替代完整备份。
- PDF 阅读已使用 PDF.js 分页渲染并支持划词标注。扫描版 PDF 如果没有文字层，仍需未来接入 OCR 才能搜索或选择文字。
- 区域批注保存本地 PNG 预览和相对坐标，可重新框选但不提供 Logseq 式边缘拖动微调。批注不写回原 PDF，不能作为带高亮的 PDF 文件交给其它阅读器；完整备份会保存批注与引用。
- “矩形高亮”可整块透明填充并摘录区域文字/截图，扫描页也能框选，但不提供 OCR 或自动语义分区。重新框选保留旧摘录/节点标题；旧文字标注无法可靠重锚定时仍回退旧坐标。
- 分栏中新保存的批注自动生成文献子节点，但不会自动转换全部旧批注；独立阅读页仍手动选目标。撤销节点不等于删除独立批注。
- SHA-256 保证相同 PDF 复用同一身份。不同版本/排版的 PDF 被视为不同论文，不会自动迁移旧坐标或猜测原文位置。
- 1.7.8 起阅读区支持上下连续滚动，提供分栏、页码、搜索、缩放和适应宽度；OCR、手绘批注与全局知识图谱尚未实现。
- 全文搜索会在首次搜索时按页提取文本并缓存于当前阅读会话；特别大的论文第一次搜索可能需要等待，但不会预先渲染全部页面。
- 第一版面向 PC Chrome/Edge。阅读器在窄屏提供基础抽屉布局，但完整移动端编辑体验和深色主题尚未交付。
- Windows 安装包尚未使用可信商业签名，SmartScreen/应用控制可能提醒或拦截；不要关闭系统保护或规避拦截，可改用本地网页/PWA。自动环境的 `ELECTRON_RUN_AS_NODE=1` 也曾导致直接退出，启动时仅移除子进程该变量。
- 源码、网页构建、安装包、已安装 EXE 和旧公网部署不会自动同步；原生桌面没有自动升级服务。PWA 首次加载和更新需可访问来源，缓存不是随意清数据后仍能首次离线打开的保证。
- PNG 使用 Mind Elixir 官方导出插件导出完整脑图；极大的图片仍受浏览器 Canvas 最大尺寸和内存限制。
- 1.7.9 的生产回归覆盖 5,000 节点的新增、撤销/重做和刷新持久化，常见编辑尽量增量更新；复杂结构编辑仍有完整布局成本。未实现思维导图视口虚拟化，全部展开的节点仍占用 DOM；大量图片、长富文本和低内存设备可能卡顿，桌面实测不代表安卓真机速度。详见 PERFORMANCE.md。
