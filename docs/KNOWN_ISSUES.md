# 已知限制

当前没有阻断本地编辑、保存或构建的已知 Bug。以下是明确的产品边界：

- 资料只自动保存在当前浏览器配置中，不会自动跨设备同步。清理站点数据、卸载浏览器或重装系统前必须先创建完整备份。
- 应用不连接任何网盘账号。完整备份由用户保存到本地文件夹或移动硬盘；如果用户自行使用同步盘，也可以选择其本地同步目录。
- 大纲编辑已成为默认入口，并已支持局部富文本与多选批量操作；概要、跨主题连接线和完全自研的导图渲染器仍在后续重构范围内。
- `.researchmind` 文件中的附件和 PDF 使用 Base64 表示，文件会比原始二进制总量大约增加三分之一；超大资料库导出时会占用较多浏览器内存。
- PDF 阅读已使用 PDF.js 分页渲染并支持划词标注。扫描版 PDF 如果没有文字层，仍需未来接入 OCR 才能搜索或选择文字。
- 全文搜索会在首次搜索时按页提取文本并缓存于当前阅读会话；特别大的论文第一次搜索可能需要等待，但不会预先渲染全部页面。
- 第一版面向 PC Chrome/Edge。阅读器在窄屏提供基础抽屉布局，但完整移动端编辑体验和深色主题尚未交付。
- Windows 安装包尚未使用商业代码签名证书，首次运行可能触发 SmartScreen 提醒；这不影响个人安装和使用，但公开分发前应购买受信任的代码签名证书并在构建流程中启用签名。
- PNG 使用 Mind Elixir 官方导出插件导出完整脑图；极大的图片仍受浏览器 Canvas 最大尺寸和内存限制。
- Playwright 会自动导入并编辑 500 节点脑图；更大规模（数千节点）的性能仍取决于浏览器内存和 Mind Elixir 布局成本。
