# 已知限制

当前没有阻断本地编辑、保存或构建的已知 Bug。以下是明确的产品边界：

- 云端功能需要用户自行提供 Supabase 项目并执行 `supabase/schema.sql`；仓库不含真实密钥，也不会自动部署。
- 内置示例文档采用本地可读 ID，不上传云端；新建的 UUID 文档与文件夹可正常跨设备同步。
- PDF 阅读使用浏览器原生 PDF Viewer。翻页、缩放和下载已提供，但不同 Chrome/Edge 版本对 URL 页码参数的表现可能不同；精确页数和划词标注需后续接入 PDF.js。
- 附件会立即本地保存，并在恢复网络后补传；浏览器被永久清除站点数据前，离线附件不会丢失。上传仍受 Supabase 项目单文件大小和配额限制。
- Google OAuth 已实现，邮箱登录只保留 Supabase Auth 扩展边界，尚无邮箱登录界面。
- 第一版面向 PC Chrome/Edge。保留 CSS 主题变量，但完整深色主题和移动端布局尚未交付。
- PNG 使用 Mind Elixir 官方导出插件导出完整脑图；极大的图片仍受浏览器 Canvas 最大尺寸和内存限制。
- Playwright 会自动导入并编辑 500 节点脑图；更大规模（数千节点）的性能仍取决于浏览器内存和 Mind Elixir 布局成本。
