# 文档 / 导图双向链接

更新日期：2026-10-04。源码和安装包版本：1.6.0。数据库仍为 v3，完整备份仍为 v1。

## 操作

在导图节点或文档大纲主题中输入 `参考 [[机器视觉]]，下一步 [[实验设计]]`。只有名称部分高亮；完整括号和原文继续保存。可以在同一节点中插入多个引用。

双击高亮名称打开同名文档。不存在目标时，新建同名文档并打开；仅输入语法不会立即创建空文档。跳转前提交当前文字编辑并等待本地保存完成。双击普通文字仍按点击位置进入编辑；单击、文字拖选、Backspace/Delete、中文组合输入和主题多选保留各自含义。

文档大纲底部显示“反向引用”。导图顶栏“引用”打开反向引用面板，链接进入目标导图时也会打开面板。每条来源包含文档名称和来源主题；单击展开来源的祖先节点并定位主题，两种视图均支持。大纲中的“引用”按钮滚动到页底列表。

节点 Markdown 笔记在预览中支持 `[[名称]]`；大纲内联描述也可双击引用。代码示例、转义括号、空名称和跨行名称不作为链接。导图展示链接和笔记预览链接可用 Tab 聚焦后按 Enter 打开。只读/演示可跟随已有链接，但不创建未存在文档。

## 名称和旧资料

名称匹配忽略首尾空格和大小写，进行 Unicode NFC 规范化。新建默认名称冲突时附数字后缀；主动重命名冲突时提示并保留原名。文档标题与中心主题同步。标题输入按 Enter 或失焦提交，Escape 取消。

历史资料中的同名文档不被批量改名或合并。打开对应链接时出现目标选择框，显示文件夹、节点数和更新时间。可先打开再自行重命名区分。

重命名会更新当前活动资料中的标题/笔记引用，同时保留可选 `linkAliases` 旧名称，以兼容历史版本和旧导入。旧名仍保留时不能被其他活动文档占用；歧义旧名不会批量重写。回收站文档不参与活动目标解析或反向引用；恢复与现有文档冲突时加数字后缀。

## 保存与兼容

原文语法是数据真源。展示 span 不保存为富文本；编辑时的高亮通过 CSS Highlights 绘制文字范围，不重建编辑 DOM。引用列表从当前树内容派生，按文档/节点去重，因此删除引用、撤销、软删除和恢复不需要额外同步关系表。

跨文档重命名是一次 Store 状态更新，批量文档持久化采用一个 Dexie 事务，任一记录失败则全部回滚。保存请求串行执行，导航保存失败时保留内存中的编辑并显示提示。

`linkAliases` 是文档可选字段，备份校验其为字符串数组；旧 v3 数据库与 v1 备份可继续读取。`.researchmind` 保存语法和旧名称，恢复后从内容重新得到引用。普通交换格式依然不替代完整备份。

## 与 Logseq 的适配

依据 [Logseq 官方教程](https://github.com/logseq/docs/blob/master/pages/tutorial.md) 的页面引用与 Linked References 逻辑独立实现。适配点是“一文档对应一导图”、双击跟随链接，以及反向定位到导图/大纲中的来源主题。

本次不实现块引用 `((id))`、页面嵌入、自动补全、手工管理别名、未链接引用列表或知识图谱，也不宣称完整复刻 Logseq。名称应使用能放在单行 `[[...]]` 中的文字；嵌套方括号名称不支持此语法引用。
