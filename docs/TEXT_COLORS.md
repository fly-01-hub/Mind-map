# 选中文字颜色与右键菜单（1.7.2）

本文保留该功能引入版本的设计及历史测试记录；当前发行说明以 README.md 为准。新安装为空白，测试不使用用户日常知识库。

## 使用方法

双击导图节点进入编辑，拖选需要强调的部分文字（也可用 Shift + 方向键），选区上方出现“文字颜色”色板，点击红、橙、黄、绿、蓝、紫之一即可。最后一个按钮恢复当前主题的正文颜色，不清除加粗、斜体等格式。空选区、不在节点编辑中、输入法合成、只读或演示模式不显示色板。

字色只影响选中的字符，不改其他文字，不创建导图，不生成双向链接。`[[文档名称]]` 原有链接和双击跳转保留；字色不是底色高亮。颜色写入现有经过净化的 `NodeData.richText`，导图和大纲共用内容，自动保存、重新打开和完整备份沿用原协议；数据库仍为 v3，备份仍为 v1。大纲原选区格式栏保留。

右键菜单统一图标、文字、快捷键三列，单行约 30px，常规菜单约 320×435px；删除命令使用淡红色，禁用命令仍不可操作。短窗口限制菜单高度并可滚动，子菜单和快捷键仍可用。原根因是缺少图标的条目将标签放进 20px 图标列，导致中文逐字换行。菜单关闭时不覆盖已获得焦点的新节点编辑框，避免右键新建后提前结束输入。
