# 三台个人设备双向同步

Windows 本机作为同步主机，Mac mini 和安卓平板使用浏览器。任意一台设备的导图、历史、PDF、附件、批注、节点关联及阅读进度均可上传并由另外两台接收。现有本地 IndexedDB 保存和备份继续使用。主机离线时各设备仍可本地编辑；交换更新需要 Windows 主机恢复在线。

同步主机是免费的 Node.js 服务，没有付费数据库。跨网络使用 Tailscale Personal（个人免费方案）：https://tailscale.com/docs/reference/free-plans-discounts 。三台设备安装并登录同一个个人账号，在可信设备之间建立私有网络；无需购买域名、配置路由器端口转发或分发自签根证书。HTTPS 由 Tailscale Serve 提供：https://tailscale.com/docs/features/tailscale-serve 。不要启用面向公网的 Funnel。

## 本机部署

源码需要 Node.js 24。运行 `npm run build` 后，`npm run sync:serve` 在 `127.0.0.1:4180` 提供程序和同步接口；数据默认保存在当前用户的 `.researchmind-sync`，与程序文件分离。Windows 安装部署使用 `%APPDATA%\ResearchMindSync`。

本机已经提供“枝间同步主机”启动入口、配对信息入口及“连接三台设备”入口。主机启动后，原 `127.0.0.1:4173` 网页保持不变。

1. Windows、Mac、安卓安装 Tailscale：https://tailscale.com/download ，使用同一个个人账号登录并保持连接。登录和设备授权由本人完成。
2. Windows 双击“枝间同步主机-连接三台设备”。脚本读取这台 Windows 的 Tailscale 设备域名，以 `tailscale serve --bg --https=443 http://127.0.0.1:4180` 配置私有 HTTPS。若首次出现官方 HTTPS 授权链接，由本人打开确认后再次运行入口。配对信息保存在主机用户数据目录，不放入 GitHub。
3. Windows 双击“枝间（同步版）”，仍使用原 `127.0.0.1:4173` 与原浏览器资料目录。首次配对窗口已填好地址和密钥，点一次“连接并立即同步”。原网页将同步 API 转发到本机 `4180`，不会建立另一份 Windows 知识库。
4. 在 `三设备同步/私有配对.html` 中复制给 Mac/安卓的配对链接，在两台设备的浏览器打开，点一次“连接并立即同步”。密钥放在 URL fragment，不随网页 HTTP 请求发送；进入页面后移除该 fragment，未点击连接前不上传资料。已配对后只用普通 `https://你的Windows.你的网络.ts.net` 地址。空白设备会接收主机资料，不必重复导入完整备份。需要时安装为浏览器 PWA。
5. 确认三台各显示“已同步”，先在每台依次修改一份测试导图、同步后到另两台核对，再处理正式文档。尚未经过三台真机和跨网络验证时，不应声称已经全部连通。

已有独立资料的其他设备应先导出备份。首次配对按记录合并，不清空本机；相同标识内容冲突会停止同步，不会默认用主机内容覆盖。本机导图和配对信息不上传公开代码仓库。

## 使用与边界

- 自动同步在打开、恢复网络/焦点和空闲时约每 30 秒检查；正在文本输入时等待，避免打断编辑。也可随时点“连接并立即同步”。切换设备前确认显示已同步。
- PDF/附件按 SHA-256 内容寻址，仅上传主机缺少的文件；平时只传变化记录及索引，不反复传整份完整备份。
- 离线改动保存在当前设备。不同记录的独立修改可以合并；同一条记录在共同版本后两端都发生变化时停止同步、保留两端内容。当前不提供同节点的实时协同或自动冲突合并；可先导出本机备份，人工核对后处理。不要通过清空浏览器资料解决冲突。
- 历史、回收站状态、删除和恢复也会同步；同步不是独立备份。主机保留最近 20 次元数据版本，PDF/附件对象不自动清理，仍需定期创建完整 `.researchmind` 备份。
- 配对密钥是访问个人资料的凭据，只给自己的设备。它保存在各浏览器本机设置中，不写进导图备份。断开同步不删除本机资料或主机资料。
- 主机提供持久存储和中转，不会替尚未打开网页的设备执行浏览器内同步；再次打开客户端并联网后接收更新。
- Windows 需开机且可联网。休眠、关机、Tailscale 断开时显示未连接并保留本机编辑。安卓 Tailscale 通常占用系统 VPN 通道；若正在使用其他 VPN，按实际系统提示选择连接，不关闭系统保护。

## 开发验证

`npm run test:sync` 检查鉴权、来源、文件完整性、并发提交、旧版本拒绝及元数据历史。`npx playwright test e2e/device-sync.spec.ts` 在三份独立临时浏览器资料库中验证双向导图/文件/批注交换、独立修改合并及冲突保留。测试不读取或改写日常资料库；浏览器模拟不等于 Mac/安卓真机或 Tailscale 跨网络验收。
