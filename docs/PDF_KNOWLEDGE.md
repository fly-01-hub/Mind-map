# PDF 批注与思维导图引用（v1.5.2）

## 操作

1. **推荐直接把资源管理器里的 PDF 拖到导图空白处或一个主题上。** 创建带 `📄` 图标的文献子节点并打开分栏，无需先到论文管理页上传。空白处以当前选中主题（或根节点）为父级；多个文件分别建立文献节点。
2. 单击文献节点，打开**左侧 PDF、右侧导图**；双击仍编辑节点标题。顶栏“论文分栏”也能打开已有论文。节点上的 `📄数量` 徽标定位到批注；右侧导图下方“节点来源”可展开原文与图表预览。
3. 在 PDF 上拖选文字，选择颜色，再点击高亮、下划线或批注。“区域批注”用鼠标拖框摘取图片、表格或公式；无需文字层。
   - **矩形高亮**：点阅读栏中可见的“矩形高亮”，按住左键拖出任意矩形，选择五种颜色之一，点“保存区域高亮”。整块区域半透明高亮，不是仅描边；文字、图表、扫描页都可使用，Esc 取消。分栏中自动生成子节点，有文字层时附带区域内文字，否则保留截图。
   - 保存后退出框选，可继续选择文字。笔记卡片的“重新框选区域”调整同一个区域，保持颜色、笔记及节点关联，不重复创建节点；旧图表批注仍采用描边样式。
4. 分栏中保存高亮、下划线、文字批注或图表区域，**自动在打开的文献节点下面建立子节点**，摘录保留完整内容与原文位置。中途选中别的主题，不改变文献父节点。阅读栏的“划选标注模式”可切换为“划选即高亮”或“划选即下划线”，省去每次点击浮动按钮。单独阅读页仍保留手动生成/关联，不猜测目标导图。
5. 按住卡片标题旁的拖动柄，拖到导图节点上即可引用。复制按钮复制本地引用；选中目标节点且不处于文字编辑状态时按 Ctrl+V 可关联。拖到空白处不会误关联根节点。
6. 点卡片中的节点反向定位观点，点原文或截图定位 PDF。多次点击同一来源也会重新定位，不重新加载整篇 PDF。
7. 五色、标签和批注笔记同步到所有引用卡片。区域选错时点击“重新框选区域”，调整截图，保留原 ID、笔记及所有关联。
8. 论文管理页按关键词、论文、颜色、标签和“仅未关联”筛选，选中结果后可批量关联到多个节点。
9. 节点来源中的“解除这条关联”只移除该节点的引用，保留原批注。删除有引用的批注会先提示；节点与笔记不删除。提示中的“撤销”恢复关联或批注。
10. 完整 `.researchmind` 备份包含 PDF、区域预览、批注、标签和关系。所有操作在本地完成，无新增账号、云服务或付费依赖。

## 对照 Logseq

依据官方 [PDF 实现](https://github.com/logseq/logseq/blob/master/src/main/frontend/extensions/pdf/core.cljs) 与 [DB 版本说明](https://github.com/logseq/docs/blob/master/db-version.md) 核查行为；独立实现，没有复制其 AGPL 源码或品牌。

| 功能逻辑 | Logseq | 枝间的导图适配 |
| --- | --- | --- |
| 原文作为独立知识对象 | 高亮引用与 PDF Annotation 节点 | PaperAnnotation 稳定 ID，节点只维护关系 |
| 引用与反向引用 | 复制/拖动引用到块，查看引用块 | 拖到主题、复制粘贴、已有节点多选关联；卡片返回节点 |
| 图表摘录 | 区域高亮、截图和区域调整 | 归一化拖框截图；重新框选同一批注，不丢引用 |
| 颜色 | yellow/red/green/blue/purple | 同五色，标签可分类研究证据 |
| 阅读与笔记并行 | PDF 侧栏与笔记块 | 按当前用户习惯左 PDF 右导图；文献节点打开分栏，标注自动生成文献子节点 |
| 文本与理解分开 | 原文引用到知识块 | 摘录和共享批注留在源对象，节点笔记写个人结论 |
| 删除保护 | 引用和批注的联动维护 | 明确分开解除关联/删批注/删节点，软删除可撤销 |

本次是借鉴核心知识工作流，不宣称等同完整 Logseq：仍按页阅读；不包含 OCR、PDF 内嵌写回、手绘、图谱或云同步。区域微调采用重新框选而非边缘拖动；不同内容版本的 PDF 不自动迁移批注。

## v1.5.2 三轮自审

## v1.5.0 三轮自审（历史记录）

### 第一轮：数据一致性

- 检查一条批注关联多个节点、重复关联、解除后恢复同一身份、无效目标与无效批注混合批次的原子回滚。
- 发现生成节点会覆盖共享批注笔记，改为独立节点笔记与实时来源引用。
- 新选区生成节点改为批注/节点/关系同事务写入，失败时不留下孤立批注。
- 创建过程中目标导图发生改变时拒绝过期写入，避免覆盖用户的新编辑。

### 第二轮：真实交互与视觉

- 验证文字选区、五色、已有节点多选、分栏阅读、精确定位、区域截图、拖动关联、解除/撤销及筛选批量关联。
- 修复导图引擎的子元素指针规则导致来源徽标不可点击。
- 修复浮动工具条阻止批注输入框获得焦点、窄窗口工具条位置与阅读区布局。
- 逐页截图核对图表预览、来源卡片、双向节点入口以及分栏区域；保留原独立阅读入口。

### 第三轮：边界、备份与回归
