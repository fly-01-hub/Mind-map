# 同级节点排序（1.7.3）

本文保留该功能引入版本的设计及历史测试记录；当前发行说明以 README.md 为准。新安装为空白，测试不使用用户日常知识库。

## 操作

选中节点 → 顶栏“顺序” → 选择“上移一位”“下移一位”“移到同级首位”或“移到同级末位”。电脑还可右键节点 →“调整顺序…”打开同一个菜单；安卓平板使用顶栏触屏入口，无需鼠标右键。

例如原来是甲、乙、丙、丁，选中丙后“移到同级首位”，变为丙、甲、乙、丁；其他节点按原有顺序下移。整条下级分支随节点移动，ID、文字颜色、双向链接、描述、待办、附件和关联关系不变。不会因排序创建新的节点或改变父级。

导图和文档大纲共享顺序并自动保存，支持撤销/重做；刷新或重新打开保留新顺序。Ctrl + Shift + ↑/↓ 仍可逐位排序。修正了大纲光标在文字边界时该快捷键被普通跨行导航截获的问题；普通方向键导航保留。

支持同一父节点下多选：导图 Shift 点击，大纲 Ctrl 点击圆点；所选节点按文档原顺序整体移动，而不是按鼠标点击顺序排列。不相邻的同级多选会合并为一组后移动。跨父级多选、中心节点、全部同级已选或已经到达边界时，无法执行的操作置灰；不制造多余撤销记录。改变父级仍用原有拖动/“移动到”功能。

概要成员必须连续。若一次排序会拆散已有概要，则拒绝该次排序并提示，不静默删除概要；可同时选择概要的全部主题一起移动。旧版仅记录索引区间的概要在成功排序前解析原成员，避免索引改变后错误概括其他主题。原有拖动/跨父级移动未改造，不宣称所有结构操作都具备这一新增保护。
