# 备份与导入选定导图（1.7.14）

入口均在知识库的“备份与恢复”。Windows 本地客户端与从当前源码构建的网页共用实现。

## 备份部分导图

点击“备份部分导图”，勾选一份或多份完整导图，再点“导出所选导图”。支持按名称筛选、全选当前列表及清空选择。只备份活动导图，不列出回收站；回收站资料使用完整备份保护。

生成的 `.rmpart` 包含所选导图的节点内容、样式、关系线/概要、历史版本、文件夹祖先、附件，以及关联 PDF 的文件、全部批注、阅读进度和到所选导图的关系。共享 PDF 的批注属于 PDF，本包可能包含在其他阅读场景创建的该 PDF 批注；不会携带未选导图的节点树。无关文件夹、无关论文和应用设置不打包。

备份关联的活动 PDF 或本地附件缺文件时会提示并停止，不静默生成缺失文件的备份。导图内部嵌入的图片随节点一起保存；外部 URL 仍是链接，不自动抓取外部内容。

## 导入部分导图

点击“导入部分导图”，选择 `.rmpart` 或完整 `.researchmind`，校验后勾选需要的导图并点“新增所选导图”。即使输入是完整备份，该入口也只新增所选内容；“从备份恢复”仍是替换全库的另一个入口。

导入会建立新文档、节点、附件、历史、批注和关系标识，保留现有资料。同名导图自动加编号，副本之间的文档名引用会同步调整，原文档不变。文件夹层级复制为新的文件夹记录；不会合并进已有同名文件夹。

按 checksum 复用已有活动 PDF，不覆盖原 PDF 元数据、已有批注或阅读进度；导入的批注使用新标识。相同来源文件中已导入的原文档会跳过。修改文件或重新导出会得到不同来源身份，不视为同一包。导图已进回收站但尚未永久删除时仍识别为已存在。

互相引用的导图建议一起导入。未选导图不自动携带，引用文字保持原样；分批导入后不会自动修改先前副本中的引用。自动改名时不复制会占用原名称的旧别名，避免副本抢占已有文档引用。

## 文件与安全

部分备份 JSON 使用 `researchmind-partial-backup`、版本 1，与完整备份的表结构及 Blob 编码一致，包含 SHA-256 完整性摘要。完整恢复入口拒绝部分格式；缺校验值的部分备份也拒绝导入。旧版无摘要完整备份仍可兼容读取，但没有同等损坏检测。

从1.7.14起，二进制总量达到128MiB时改用v2 ZIP结构，文件扩展名仍为`.rmpart`。清单标注部分备份来源，论文和附件分别保存并校验，避免超大Base64字符串；完整恢复入口仍拒绝部分包。新版可以读取旧JSON和新ZIP；较旧应用无法读取新ZIP包。

先校验，再在一个事务中完成新增，写入中途失败全部回滚。界面先提交编辑并暂停旧保存，完成后重读数据、保留旧撤销历史、恢复自动保存。任何部分导入都不会导入来源 meta 表。

`.rmpart`、`.rmstudy`、`.researchmind` 均未加密，不能提交到公开仓库；Git 忽略和公开包审查覆盖这三种文件。不要用部分备份替代设备之外的完整备份。

测试使用合成内容和临时配置，覆盖导出依赖范围、完整备份选取、文件完整性、事务回滚、同名/标识重建、内部引用、附件/批注/历史、重复导入，以及 Windows 安装路径实际程序的导入、PDF 正文阅读和重开。
