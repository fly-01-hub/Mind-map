# 本地资料保护（1.7.11）

应用默认只在本机保存资料，没有云端副本。不能保证断电、浏览器清理、卸载、磁盘损坏等所有情况零丢失。完整 `.researchmind` 文件应另存到独立目录、移动硬盘或自己选择的同步目录。

## 1.7.11 复查修复

- 草稿按文档、节点和字段分别保留；只有对应内容进入节点树后才确认，不再在任意失焦后直接清空。切换节点或文档时把待提交内容写回原文档，避免详情编辑框卸载后前一条笔记被下一条替代。详情输入框明确绑定所属文档/节点；取消文档重命名不会重新恢复已取消的名称。
- 多行节点恢复记录与编辑器使用相同的文字读取规则；富文本清理保留浏览器生成的块级换行，避免恢复时两行文字被拼接。连续多行输入、退出编辑及切换大纲后能正常确认保存。
- 自动保存比较数据库的实际基线内容；恢复记录同时核对变更节点的原值和目标值，不再仅凭版本号与时间相同就认定内容已保存。冲突保留原资料和恢复副本；删除可选字段也会进入差异记录。多个节点草稿恢复到同一文档，不产生无意义的互相冲突。
- 普通附件逐个合并到最新的所属节点；某个文件失败会显示文件名，并保留其他已成功添加的附件。上传期间切换节点/文档不会把附件添加到后来打开的文档。
- 新导出的完整备份在原 v1 格式中增加可选 SHA-256 完整性校验，覆盖元信息、全部表和二进制文件的 Base64 内容。校验失败在替换原库前停止。旧版无校验值的 v1 备份仍可导入，但无法提供同等的损坏检测；校验不代表加密或来源认证。
- 网页下载的临时文件地址保留 60 秒，避免下载尚未接管时立即释放；有未能提交的草稿时，网页自动重载与完整库替换会停止。失败提示也提供恢复记录导出入口。

## 新增保护

- 节点文字、大纲文字、节点详情的笔记/代码/公式/链接/表格，在输入时保留本机恢复记录，不再只依赖失去焦点后的提交。恢复记录用未变节点引用和节点差异，避免反复序列化整个大型导图。
- 文档和文件夹每次变动先更新同步恢复记录，再进入原有 350ms 防抖保存。IndexedDB 事务成功后只清理对应已确认内容，保存中发生的新编辑继续保留。恢复前比较版本；遇到较新的数据库内容，保留原文档，并尽量把未保存内容恢复为独立副本。
- 关闭、切后台、安卓暂停和网页更新时提交当前输入框，并尝试完成保存。PWA 自动更新和控制器变化共用保存后再重载的路径。未成功写入时停止自动重载，保留恢复记录并显示失败提示。
- 自动重试失败写入；恢复焦点也会重试。用户可点击“重试保存”或“导出当前资料”。导出使用最新内存节点树和数据库中已有的附件/PDF，因此保存失败时也能尽量保护当前窗口里的编辑。
- 数据库读取或恢复记录解析失败时停止编辑，显示重新读取/导出恢复记录入口，不能把读取失败当成首次空白并继续写入。
- 支持 Web Locks 的浏览器同一知识库只允许一个写入窗口；其他窗口等待前一个关闭后重新读取。文档/文件夹事务还会检查保存基线，拒绝旧窗口静默覆盖较新内容。没有自动合并多窗口并行编辑，也没有实时协作。
- 文档与文件夹作为同一事务写入，避免只保存一半；数据库请求严格提交持久性。历史版本清理与新版本写入也处于一个事务，写入失败保留原历史。
- 主动请求浏览器持久存储，以减少存储压力触发的自动回收。是否授予由浏览器决定，申请结果在“备份与恢复”中显示；这不阻止用户手动清理数据。

## 恢复完整备份

先提交当前编辑并排空保存队列，再暂停旧的自动写入。验证待导入文件后，恢复前将当前完整 11 表（含 Blob）保存到独立的本机安全副本数据库，最多保留最近两份。安全副本无法写入则停止恢复，原库不替换。

随后在主数据库的单个事务中整体替换；格式错误、主键/节点标识重复、二进制解码失败和事务写入失败均不会留下半份替换结果。恢复后先重新读取文档、文件夹、论文并清空旧内存撤销栈，再恢复自动保存，避免旧定时器把旧树重新写回。重新读取失败会继续停写，要求重新打开。

再次验证了实际替换事务：在表已开始清空/写入时注入失败，导图、PDF 二进制与元信息保持原值，而不只是检查导入前的格式拒绝。

“备份与恢复 → 导出恢复前安全副本”可导出此前完整资料，再通过普通恢复流程找回。浏览器下载方式只提示已开始下载，要求确认文件完成；原生文件接口和文件选择器等待实际写入完成后才提示已保存。

## 存储与限制

主数据库仍为 `zhijian-knowledge-db`、schema v3、完整备份格式 v1。安全副本数据库为 `researchmind-safety-snapshots`，schema v1；恢复记录在同源 localStorage 的 `researchmind-recovery-v1:` 命名空间中，都是未加密的本机资料，不上传 GitHub。恢复记录只保护未确认的编辑差异，不是完整备份，也不适合直接导入普通恢复入口。

清理站点/应用数据会同时清除主库、安全副本和恢复记录。卸载、设备丢失、磁盘故障和严重系统崩溃仍可能丢失全部本机副本；浏览器也不允许网页在没有用户选择的情况下任意写入外部备份目录。存储被禁止或恢复记录超出配额时会明确提示，并在尚有未保存内容时请求离开确认。请在外部备份完成前保持窗口打开。

若旧窗口已永久删除恢复记录所依赖的节点，或记录损坏，自动恢复可能停止；原数据库保持不被覆盖，并可先导出恢复记录排查。冲突恢复副本不能保证自动重建所有跨文档/PDF 来源关系，需要核对。

## 验证

独立临时浏览器中实际触发渲染进程崩溃，验证未失焦的节点文字和详情 Markdown 笔记能恢复；覆盖大纲立即刷新、写入配额错误、导出最新内存内容、重试、读取失败、多窗口交接、恢复前完整快照和防止旧保存任务覆盖。生产构建覆盖更新重载时仍在输入的文字，以及 5,000 节点的新增、撤销/重做和重开。

这些验证不读取日常知识库，不代替真实断电、硬盘损坏或安卓真机被系统杀进程的测试。安卓仍需覆盖安装，不能先卸载带资料的旧版。
