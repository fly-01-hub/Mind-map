# 编辑时画布保持位置（1.7.4）

本文保留该功能引入版本的设计及历史测试记录；当前发行说明以 README.md 为准。新安装为空白，测试不使用用户日常知识库。

## 需求与实现

单击父节点准备添加子节点，不应让整张导图突然居中。普通输入、提交编辑、新增下级与内容更新尽量保持当前操作节点的屏幕位置；不是冻结节点排版，分支增加仍需正常布局。只有编辑框/当前输入点超出安全可视范围时，按越界距离平移，不自动缩放或居中。边缘留 16px 安全余量、约 40px 加号空间，并避开底部主题工具栏。

Mind Elixir 的 `selectNode` 会调用自动居中式 `scrollIntoView`。适配器在实例层屏蔽普通选择的自动定位，保留显式搜索/引用导航的强制定位；不改 node_modules。`.map-container` 使用 `overflow: clip`，避免隐藏滚动容器因焦点/光标自动滚动，保留应用自己的平移、缩放和框选。

刷新布局和结束编辑时，按稳定节点 ID 恢复操作节点左上角屏幕位置，避免树高度、宽度和缩放中心变化造成跳动。整棵显示树的根 ID 改变（导入/进入或退出子树）属于主动导航，允许居中，避免大型导图的新根留在屏幕外。首次加载、手动“居中”“适应画布”、搜索和反向引用定位保留。

编辑框大小、输入、方向键/合成结束、窗口及 visualViewport 尺寸变化触发按帧合并的边界测量。超长节点无法整体放入屏幕时，超限的轴跟随当前输入点，而非反复追逐两端。测量不重写正文、富文本、选区或输入法状态，不逐按键提交资料。平移本身不触发跟随，不与用户的中键/空格拖动争夺位置。退出编辑或销毁适配器时清理观察器、监听与待执行帧。

窗口缩小导致非编辑的选中节点完全不可见时，仅做必要平移；普通选中造成工具栏/头部尺寸变化时，仍可见或部分可见的节点不因此移动。节点变动时其他分支的正常排版变化，不等同于自动平移画布。

## 数据与安全

数据库仍 v3，完整备份仍 v1，无数据迁移或新依赖；只修改适配器视口策略和画布样式。原节点排序、文字颜色、双向链接、＋跟随输入、大纲共享内容、PDF/附件和本地备份保留。测试在独立浏览器/Electron 配置内建立导图，不写用户的正式库、不执行覆盖恢复。
