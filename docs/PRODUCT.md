# 产品定义

枝间面向长期整理论文、科研问题、项目思路和创作设定的个人用户。大纲和思维导图共享同一棵节点树，都支持编辑与整理层级；重内容进入可收起的 Node Inspector。当前用户最常使用思维导图，后续优先验收导图的鼠标/键盘操作与论文分栏，而不是用大纲代替导图编辑体验。

## 核心原则

- Local-first：编辑立即反馈，并自动保存到当前浏览器或桌面配置的 IndexedDB，无应用账号或云数据库。
- 数据可带走：一个完整备份文件包含结构化数据和所有二进制资料，可保存到百度网盘或其他位置。
- 双视图共享：不维护第二套内容；当前无偏好时默认大纲，切换后记住选择，这是现有默认行为，不代表用户偏好大纲。
- 结构优先：标题、任务、少量标签与提示图标留在大纲和导图，笔记和附件进入详情栏。
- 键盘优先：Enter、Tab、Shift+Tab、行首 Backspace、方向键和剪贴板命令支持连续构建知识树，并保护中文输入法组合态。
- 可替换引擎：领域 NodeData 是唯一数据源，Mind Elixir 只存在于适配层。

## 当前范围

当前 1.5.2 包含共享树、连续输入、局部富文本、多选批量操作、缩进/提升、合并、拖动重排、概要、关联线和双视图切换。本地富节点、文档管理、搜索、历史、多格式导入导出、完整备份/恢复均保留。PDF 可直接拖入建立文献节点，单击打开左 PDF / 右导图；新标注自动成为固定文献父节点的子节点，并支持独立来源、多对多引用、反向定位和自由矩形高亮。AI 接口仅返回未启用，不上传内容或调用模型。

参考幕布的通用操作和 Logseq 的 PDF 证据工作流，独立实现，不承诺完整 1:1 功能对等。用户需求、已实现与限制的详细区分见 [redme.txt](../redme.txt)。

不包含账号登录、自动跨设备同步、多人实时协作、公开分享、移动端专项适配、OCR、服务端全文索引和真实 AI 调用。
