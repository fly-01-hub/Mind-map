# 产品定义

枝间面向长期整理论文、科研问题、项目思路和创作设定的个人用户。核心体验是低干扰的结构化大纲：大纲负责快速输入和整理层级，思维导图负责查看全局，两种视图共享同一棵节点树；重内容进入可收起的 Node Inspector。

## 核心原则

- Local-first：编辑立即反馈，并自动保存到当前浏览器的 IndexedDB。
- 数据可带走：一个完整备份文件包含结构化数据和所有二进制资料，可保存到百度网盘或其他位置。
- 大纲优先：编辑从线性输入开始，导图是同一份结构的另一种呈现，不维护第二套内容。
- 结构优先：标题、任务、少量标签与提示图标留在大纲和导图，笔记和附件进入详情栏。
- 键盘优先：Enter、Tab、Shift+Tab、行首 Backspace、方向键和剪贴板命令支持连续构建知识树，并保护中文输入法组合态。
- 可替换引擎：领域 NodeData 是唯一数据源，Mind Elixir 只存在于适配层。

## 当前范围

当前版本已完成大纲优先重构：共享树、连续输入、局部富文本、多选批量操作、缩进/提升、合并、拖动重排、概要、关联线和双视图切换均已交付。本地富节点、文档管理、搜索、历史、多格式导入导出、完整备份/恢复与论文阅读继续保留。AI 仅保留离线接口，不会上传内容或调用模型。

不包含账号登录、自动跨设备同步、多人实时协作、公开分享、移动端专项适配、OCR、服务端全文索引和真实 AI 调用。
