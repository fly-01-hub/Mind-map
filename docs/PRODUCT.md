# 产品定义

枝间面向长期整理论文、科研问题、项目思路和创作设定的个人用户。核心体验是低干扰的单侧右向知识树：画布负责快速组织结构，重内容进入可收起的 Node Inspector。

## 核心原则

- Local-first：编辑立即反馈，并自动保存到当前浏览器的 IndexedDB。
- 数据可带走：一个完整备份文件包含结构化数据和所有二进制资料，可保存到百度网盘或其他位置。
- 结构优先：标题、任务、少量标签与提示图标留在画布，笔记和附件不把节点撑成卡片。
- 键盘优先：Enter、Tab、Shift+Tab 和剪贴板命令支持连续构建知识树，并保护中文输入法组合态。
- 可替换引擎：领域 NodeData 是唯一数据源，Mind Elixir 只存在于适配层。

## 当前范围

当前版本完成本地编辑、富节点、文档管理、搜索、历史、导入导出和完整备份/恢复。科研阅读流程覆盖 PDF 上传与去重、PDF.js 分页阅读、搜索、文字选择、高亮/下划线/批注、标注生成节点、节点与原文双向定位，以及保留论文来源的 Markdown 导出。AI 仅保留接口和离线 Mock，不会上传内容或调用模型。

不包含账号登录、自动跨设备同步、多人实时协作、公开分享、移动端专项适配、OCR、服务端全文索引和真实 AI 调用。
