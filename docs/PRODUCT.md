# 产品定义

枝间面向长期整理论文、科研问题、项目思路和创作设定的个人用户。核心体验是低干扰的单侧右向知识树：画布负责快速组织结构，重内容进入可收起的 Node Inspector。

## 核心原则

- Local-first：编辑立即反馈，先保存 IndexedDB，再异步同步 Supabase。
- 数据不丢失：云端失败不影响本地；版本冲突保留带时间戳的恢复副本。
- 结构优先：标题、任务、少量标签与提示图标留在画布，笔记和附件不把节点撑成卡片。
- 键盘优先：Enter、Tab、Shift+Tab 和剪贴板命令支持连续构建知识树，并保护中文输入法组合态。
- 可替换引擎：领域 NodeData 是唯一数据源，Mind Elixir 只存在于适配层。

## 当前范围

当前版本完成本地编辑、富节点、文档管理、搜索、历史、导入导出以及可选的 Google/Supabase 跨设备能力。科研阅读流程已经覆盖 PDF 上传与去重、PDF.js 分页阅读、搜索、文字选择、高亮/下划线/批注、标注生成节点、节点与原文双向定位，以及保留论文来源的 Markdown 导出。AI 仅保留接口和离线 Mock，不会上传内容或调用模型。

不包含多人实时协作、公开分享、移动端专项适配、OCR、服务端全文索引和真实 AI 调用。
