# 产品体验评审与优化路线

最近评审：2026-10-02

2026-10-04 文档对齐：下列研究与评审是历史记录，不代表本轮重新浏览或界面验收；最新功能、用户优先级和验证范围见 [redme.txt](../redme.txt)。

## 产品定位

枝间不是通用白板，而是面向个人研究与长期知识整理的本地优先工具。核心闭环应保持简单：建立结构 → 放入论文 → 阅读与标注 → 从原文生成知识节点 → 备份带走。

## 参考项目与采用原则

- [Excalidraw](https://github.com/excalidraw/excalidraw)：本地优先、开放文件格式、快捷键帮助容易找到。枝间采用“完整备份可带走”和画布帮助入口，但不引入自由绘图工具的复杂度。
- [tldraw](https://github.com/tldraw/tldraw)：把高频上下文操作放在画布前景层，并允许按场景精简工具栏。枝间保留节点旁快捷操作和底部画布控制，同时给搜索、详情增加文字标签。
- [Mind Elixir](https://github.com/ssshooter/mind-elixir-core)：键盘、工具栏和上下文菜单是脑图编辑的三条互补入口。枝间继续使用适配层控制引擎，并补齐可发现的快捷键说明。
- [Wren](https://github.com/thewrenapp/wren)：论文、附件、阅读器与批注应形成一个本地资料库，而不只是把 PDF 当普通文件。枝间保留独立 Paper、Annotation 和关系模型。
- [Paperview](https://github.com/Carstenhanekamp/Paperview)：无需账号即可打开本地论文并延续阅读状态。枝间同样把本地阅读作为默认路径，不再出现“等待云端同步”的文案。

以上只用于产品模式研究，没有复制这些项目的代码或视觉资产。

## 幕布兼容基线

本轮以幕布公开帮助中心为交互事实来源，采用的是通用操作模式，不复制其商标、图标、文案或专有视觉资源：

- [快速上手](https://mubu.com/help/50)：大纲负责连续输入和层级整理，思维导图负责全局查看；圆点、折叠和拖动是主题操作的核心入口。
- [快捷键列表](https://mubu.com/help/14)：Enter 新建同级，Tab / Shift+Tab 调整层级，Shift+Enter 进入描述，Ctrl+Shift+L/K 管理待办，Ctrl+[/] 进入或退出主题，Ctrl+/ 打开快捷键面板。
- [文字样式](https://mubu.com/help/25)：鼠标选择局部文字后出现悬浮格式栏；粗体、斜体、下划线、颜色、链接、代码与挖空均针对真实选区。
- [描述功能](https://mubu.com/help/20)：描述是主题的补充说明，Shift+Enter 在主题与描述之间切换，默认弱化显示以保持大纲的阅读节奏。
- [思维导图编辑](https://mubu.com/help/28)：导图选中主题后显示上下文操作栏，可创建同级/下级、修改样式、完成任务、编辑描述与插入内容。
- [概要与连接线](https://mubu.com/help/122)、[连接线](https://mubu.com/help/118)：概要只覆盖相邻同级主题；连接关系从已选主题开始，在第二个主题处完成。

由此确定枝间的兼容原则：一份树数据、两种视图；文字选区优先于主题选中；Shift+点击和拖框执行多选而不是删除；删除必须由明确的 Delete/Backspace 或按钮触发；重功能退到详情栏，高频主题操作留在上下文工具栏。无偏好时默认大纲是当前实现；用户主用导图，后续按导图交互验收，不把大纲优先当作用户的最新需求。

## 本轮发现

1. 功能发现成本高：搜索、节点详情、历史和快捷键藏在无文字图标或菜单中。
2. 文献拖放缺乏事前提示；功能虽然存在，但用户只能靠试错发现。
3. 知识库信息密度失衡：大面积留白，却没有文档、节点、文件夹规模概览。
4. 卡片视图按钮不可用，属于会削弱信任的“死控件”。
5. 编辑器缺少缩放百分比，用户难以判断当前画布尺度。
6. 取消云端方案后，论文阅读器仍残留云端加载文案。

## 已完成

- 知识库增加导图、节点和文件夹概览，以及 PDF 拖放提示和本地保存状态。
- 列表/卡片视图均可使用，并记住用户选择。
- 编辑器显示节点数；搜索和详情改为带文字的高频操作。
- 增加操作指南、快捷键表、画布常驻 PDF 提示和 `?` 快捷入口。
- 画布增加缩小、百分比、放大、适应和居中等完整控制。
- 节点详情栏加宽，改善论文标题、附件名称和长笔记的可读性。
- 清除论文阅读器的云端遗留文案。
- 修复导图双击编辑后鼠标拖选文字会退出编辑的问题，并增加真实鼠标回归测试。
- Shift+Enter 改为主题描述编辑；大纲内联显示描述，导图在详情栏直接聚焦描述。
- 导图空白拖动恢复为框选，Shift+点击执行多选；移除非标准且危险的“拖框即删除”。
- 导图增加底部主题操作栏；大纲增加行内快捷工具，并补齐幕布式视图、演示、待办、完成、返回上级和主题移动快捷键。
- 导图支持 Shift+方向键连续多选、Ctrl+A 全选可见主题，以及多选后的复制、待办、完成、概要、连接和删除。
- 导图补齐 Ctrl+Shift+L/K、Ctrl+B/I/U、Ctrl+Enter、Alt+颜色、层级折叠与同级移动等高频键盘操作；连续操作时保持选中节点，不再因引擎刷新丢失焦点。
- 导图局部文字支持粗体、斜体、下划线、删除线、颜色、代码与挖空，并能在导图/大纲切换和刷新后保留。
- 连接线支持从当前主题进入点选目标主题的创建模式；相邻同级主题可直接在导图中创建概要。
- Alt+Enter 或底部主题栏可插入本地图片；图片作为本地文档内容保存，不上传第三方。
- 搜索结果改为展开、定位并居中目标节点，不再误进入孤立分支。
- 只读与演示模式已封住键盘、右键、拖放、详情栏和主题栏的写入入口；演示仍保留缩放和平移。
- 中心主题与文档标题保持同步，避免导图标题和知识库标题分叉。

## 下一阶段候选

按价值与成本排序：

1. 命令面板：统一搜索文档、节点和操作。
2. 论文元数据编辑：作者、年份、期刊、DOI 和引用格式。
3. 大型导图的缩略导航图与大纲视图。
4. 深色主题与更完整的窄屏编辑适配。

暂不优先：多人协作、在线账号、装饰性模板市场和强制 AI 入口。这些能力会扩大维护面，但不会直接改善当前个人研究闭环。
